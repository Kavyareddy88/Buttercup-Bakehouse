# Installation & customization

1. Extract the ZIP.
2. Open `pages/index.html` or run the folder through a local static server.
3. Edit shared design tokens in `assets/css/style.css`.
4. Edit each page in `pages/` and its matching stylesheet in `assets/css/`.
5. Edit product and journal data in `assets/js/main.js`.
6. Replace sample contact details and connect enquiry forms before publishing.
